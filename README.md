# ACCOMPANY TECH 출근 보고

https://channnndol.github.io/accompany-attendance/

로그인 없이 사용하는 ACCOMPANY TECH 전용 출근 보고 작성기입니다.
2026년 10월 20일 기준 기본 명단 16명과 이름 순서를 반영했습니다.

1. 날짜와 변동 인원을 선택하고 연차·공가·반차·기타 결근·퇴사 사유를 고릅니다.
2. 빠진 인원이나 신규 입사자를 오늘 명단에 추가할 수 있습니다.
3. ‘확인 · 글 만들기’로 작성 후 검토·수정하고 복사 또는 공유합니다.

반차는 출근 인원에 포함되며 반차 항목에 표시됩니다. 퇴사자는 출근·정원에서 제외하고 퇴사 항목에 표시합니다. ‘퇴사 처리 · 기본 명단에서 제거’를 누르면 이후 기본 명단에서도 제외되며 같은 화면에서 취소할 수 있습니다.

오늘 추가한 사람을 이후에도 포함하려면 기본 명단에도 등록하세요. 기본 명단은 각 브라우저에 저장되며 다른 사람이나 기기와 동기화되지 않습니다. 세보5D 페이지와 별도 저장 키를 사용합니다. 매일의 선택과 완성 글은 다시 열면 초기화됩니다.

아이폰 Safari, 안드로이드 Chrome·삼성 인터넷 등에서 사용합니다. 공유 메뉴의 카카오톡 노출은 기기에 따라 다릅니다. 카카오톡으로 자동 전송하지 않으며 앱과 대화방은 직접 선택합니다.

## 개발 및 배포

- `node test.cjs`: 요청 양식 전체 일치, 인원·휴가·반차·신규·퇴사 계산
- `node build.cjs`: 자체 완결 HTML을 `docs/index.html`, `out/index.html`, `dist/AccompanyAttendance.html`에 생성
- `node verify-ui.cjs`: 모바일 UI 및 복사·공유·명단 변경 검사
- `node verify-startup.cjs`: WebKit·Chromium 시작·복원 검사

브라우저 테스트는 `PLAYWRIGHT_MODULE`로 Playwright 설치 경로를 지정할 수 있습니다. 실제 휴대폰 및 카카오톡 전송을 대체하는 검증은 아닙니다.

GitHub Pages는 `main` 브랜치의 `/docs`를 게시합니다. 소스 수정 후 빌드하여 배포 파일도 함께 커밋하세요.
